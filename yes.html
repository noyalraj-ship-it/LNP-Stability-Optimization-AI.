Submission Requirements

Important: CSV format strictly required. Ensure your file uses exact column headers for successful client-side parsing.

Required Column Headers:

  • lnp_id, ionizable_lipid, peg_lipid, sterol_lipid
  • helper_lipid, lipid_molar_ratio
  • particle_size_nm_std, pdi_std, zeta_potential_mv_std
  • encapsulation_efficiency_percent_std, target_type

Data Quality Guidelines

  • Ensure all numerical fields are formatted correctly without units (e.g. use "150" instead of "150 nm").
  • Use standard naming conventions for commonly known lipids.
  • Fill out optional fields such as DOI and Paper Title if the data is published.
  • Double check the lipid molar ratio format (e.g., 50:1.5:38.5:10).

Help & Documentation

HelixGraph is designed to run entirely locally in your browser for maximum privacy and performance. All filtering, pagination, and visualizations are rendered on your machine using the loaded CSV file.

Quick Tips

  • Use the Home tab to filter and browse specific formulations.
  • Scroll down on the Home tab to view the Data Analytics Dashboard.
  • Use the Upload tab to ingest your custom LNP spreadsheet offline.
  • Visit the Lipid Table tab to view SMILES and mapping for all cataloged lipids.
